## 🎯 About Me

- ☁️ **AWS Certified Solutions Architect – Associate**: Passionate about architecting scalable, resilient, fault-tolerant, and cost-optimized cloud solutions adhering to the **AWS Well-Architected Framework**.
- ⚙️ **DevOps Engineer Associate**: Hands-on experience engineering automated **CI/CD pipelines** (**Jenkins**, **GitHub Actions**), reducing deployment friction and ensuring seamless releases.
- 📦 **Containerization & Orchestration**: Containerizing applications with **Docker** and managing workloads with **Kubernetes**, focusing on microservices reliability and automated scaling.
- 🏗️ **Infrastructure as Code (IaC)**: Automating cloud resource provisioning and environment repeatability through **Terraform** and configuration scripts.
- 🐧 **Linux Systems Engineering**: Solid background in production Linux server administration (Ubuntu, Debian, RHEL), kernel/system performance tuning, and advanced **Bash / Shell automation**.
- 🛡️ **DevSecOps & Network Security**: Strong emphasis on security posture — implementing **IAM least privilege**, **VPC isolation & peering**, **PKI / SSL/TLS encryption**, and network auditing (**Wireshark**, **Nmap**).
- 🎓 **CDAC PG-DITISS Alumnus**: Formal post-graduate background in IT Infrastructure, Systems, and Cyber Security.
