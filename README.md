## 👨‍💻 Professional Summary

I am a **DevOps Engineer Associate** and **AWS Certified Solutions Architect – Associate** dedicated to engineering resilient, scalable, and secure cloud environments. My work focuses on translating architectural requirements into production-ready cloud systems through **Infrastructure as Code (IaC)**, automated **CI/CD pipelines**, containerized workloads, and adherence to the **AWS Well-Architected Framework**.

With a strong academic foundation in **IT Infrastructure, Systems & Cyber Security (CDAC PG-DITISS)**, I bridge software delivery with reliable operations—ensuring infrastructures are immutable, observable, and secured by default.

## 📐 Engineering Principles & Focus Areas

- 🏗️ **Infrastructure as Code (IaC)**: Provisioning and version-controlling cloud resources with Terraform to eliminate manual configurations and enforce immutable infrastructure.
- 🔄 **Continuous Integration & Continuous Delivery (CI/CD)**: Constructing robust delivery pipelines using Jenkins and GitHub Actions with automated linting, container builds, security scans, and deployment gates.
- 🛡️ **DevSecOps & Cloud Governance**: Implementing security by design—enforcing IAM least-privilege access, isolating network layers with private VPC subnets, and configuring encrypted communications.
- 📈 **Observability & Fault Tolerance**: Architecting self-healing workloads with health checks, Auto Scaling, multi-AZ database replication, and proactive monitoring via Prometheus, Grafana, and CloudWatch.
